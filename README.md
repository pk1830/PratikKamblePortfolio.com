# Pratik Kamble Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run in VS Code
1. Extract this ZIP to a folder.
2. Open the folder in VS Code (`File > Open Folder`).
3. Install the **Live Server** extension (optional).
4. Right-click `index.html` and choose **Open with Live Server**. You can also open `index.html` directly in a browser.

## Customize
- Update contact details in `index.html`.
- Update experience, skills, and education in `index.html`.
- Change colors, spacing, and responsive styles in `css/style.css`.
- Mobile navigation and dynamic footer year are in `js/main.js`.

## Notes
- This is a frontend-only static site; it has no backend or database.
- The content was drafted from the supplied resume. Please review dates, current title, experience duration, and contact details before publishing.
- The resume's listed ReactJS status is represented as learning, not as professional experience.
